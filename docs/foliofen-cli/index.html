Human-in-the-loop auth

Start a visible Chrome profile, complete portal login and MFA yourself, and keep authenticated cookies and exports on local disk with 0600 permissions.

Patient & origin guards

Verifies exact active-patient and portal-origin matches before mutating local state so proxy family charts never collide.

PHI-free summary mode

Exports human-readable Markdown and chunked JSONL, while summary mode reports coverage counts without emitting clinical text or names.
