Local-First Health Utility · Public Beta for macOS & Chrome

Patient-owned records. Zero cloud custody.

Foliofen CLI (@lifan-builds/mychart-cli) exports records you can already view in an Epic MyChart portal into deterministic local Markdown or JSONL—keeping login, MFA, cookies, and medical files strictly on your computer.

Human-in-the-loop auth

Start a visible Chrome profile, complete portal login and MFA yourself, and keep authenticated cookies and exports on local disk with 0600 permissions.

Patient & origin guards

Requires --require-active-patient and optional --source-host matching before mutating local state so proxy family charts never collide.

PHI-free summary mode

Exports human-readable Markdown and chunked JSONL, while --json-summary reports coverage counts and skips without emitting clinical text or names.
