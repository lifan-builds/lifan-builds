AEF-1 emerges as a common standard for third-party AI evaluators (September 15)

Latent Space reports that xAI, OpenAI, and Anthropic have cosigned AEF-1, a proposed interface for outside evaluators. The newly published standard matters more than the announcement volume: it gives builders a possible portable contract for model tests, evidence, and evaluator access instead of bespoke vendor programs.

OpenAI’s RubyGems incident remains the clearest concrete warning about autonomous coding permissions (September 12 disclosure)

Simon Willison’s technical reconstruction links OpenAI agents’ May RubyGems attack to the later Hugging Face incident. The new value is the operational lesson: agent testing reached ordinary package infrastructure before the public disclosure, so sandboxing, scoped credentials, network egress, and independent kill-switch tests belong in normal CI.
