The most useful advances concern what agents should do, what they should remember, and how their tools expose state; a new breach investigation shows why those same traces and interfaces need careful boundaries.

TOP 10 · November 13, 2026 investigation; October 29 attack

Cursor traces its extension breach to credentials in historical agent logs

A key exposed at Fireworks let attackers copy historical non-Privacy-Mode traces; unredacted credentials enabled further access and tampering with Cursor's extension cache. At most 5,000 users potentially received malicious Claude Code builds—not 5,000 confirmed infections—and Cursor says live inference and Privacy Mode prompts/code were unaffected.

TOP 10 · November 13, 2026 benchmark

Deepnote tests whether workplace agents know when to stay silent

Twelve model configurations face 50 situations in a synthetic company spanning 11 services, including ten where intervention is unnecessary; correct silence averages 62.5%, and unnecessary interventions consume roughly 1.8 times the time and cost. This changes the evaluation target from producing a good message to first deciding whether help is needed.

TOP 10 · November 12, 2026, 18:58 UTC paper

CoReMem measures which coding memories actually help the next task

Its key experiment compares the next task with and without memory from an identical inherited repository state, favoring code locations and executable checks over expansive summaries. Combined with actor post-training, the 27B system raises ChainSWE resolution from 21.0% to 25.7%, with 17% fewer steps and 11% fewer total cache-aware tokens, including memory operations.

TOP 10 · November 15, 2026, 12:10 UTC essay

Raschka explains RoPE conventions that can quietly break checkpoint ports

This newly published derivation connects positional-embedding mathematics, executable PyTorch examples and modern architectures using partial RoPE or mixtures with no positional embeddings. A concrete trap: split-half and interleaved rotations are equivalent only with matching feature reordering; swapping implementations on unchanged vectors can change attention scores.

TOP 10 · November 12, 2026, 22:12 UTC release

Claude Code adds opt-in JavaScript orchestration for related tool calls

Code Mode lets Claude batch, parallelize and filter tool operations in JavaScript before returning selected output to the model. Try it on repetitive edits or searches requiring many related calls, measuring task quality and elapsed time against ordinary tool use; no independently verified productivity gain is established here.

TOP 10 · November 12 beta; November 13, 2026 practitioner analysis

Vercel UI SDK exposes component actions and cuts agent round-trips

The roughly three-week-old project gives agents component state and actions through snapshot/act/query, while shared behaviors handle keyboard and accessibility mechanics. A practitioner reports five runs per arm on the same form: ten tool calls became two, 9.6 seconds became 3.7, and both paths succeeded five times; text consumption barely changed, suggesting fewer model round-trips drove the gain.

TOP 10 · November 12, 2026, 18:52 UTC paper

NOPO learns from reliable failures without rewarding unverified successes

Incomplete unit tests can reject a solution decisively without certifying that a passing solution is correct; NOPO treats those passes as unlabeled and suppresses trusted failures instead. On the authors' 4B model comparisons, mean pass@16 reaches 52.86 versus GRPO's 48.93, making this a practical challenge to treating every verifier pass as positive training reward.

Cloudflare opens Kitesurf’s browser engine for self-hosted agent workloads

Previously introduced in August, Kitesurf now ships Apache-2.0 code that parses HTML, applies CSS, executes JavaScript and renders screenshots on Workers without a Chromium container. CDP compatibility offers a concrete integration route for existing automation clients, while opening the implementation makes rendering and automation failures inspectable.
