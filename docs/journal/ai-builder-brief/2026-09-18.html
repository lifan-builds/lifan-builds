Anthropic quantifies AI-led R&D and oversight across 30,000 internal agents (September 17)

Anthropic published three proposed measurements for frontier-lab development: how much AI R&D is performed by AI, how agents are overseen, and how compute is allocated. As of August, its self-built index says Claude “leads” 26% of R&D work, up from under 1% in February; more than 90% is at least collaborative, but none is fully autonomous.

Claude-assisted researchers disclose a chained breach of OpenAI’s internal code access (September 18 disclosure; July 25 incident)

Hacktron AI disclosed that a three-person bug-bounty team used Claude to chain a libheif memory-corruption flaw in OpenAI’s Discourse forum with an account-takeover path, compromise employee ChatGPT/Codex accounts, and reach an employee-linked OpenAI GitHub organization. The striking capability change was concrete: the researchers say Opus 4.8 repeatedly failed to build the exploit, while Opus 5 succeeded within hours of release.

Anthropic redesigned Claude Projects around a coordinator that scopes work, launches and steers parallel Claude Code cloud sessions, reviews results, shares memory across threads, opens pull requests, runs tests, and keeps working after the user leaves. Each thread gets its own branch and repository copy; overlapping edits still surface as ordinary merge conflicts.

DeepMind’s new institute proposes reasoning-transparency limits and held-out frontier tests (September 17)

The DeepMind Institute launched with four essays intended to expose disagreement rather than a single company line. The most actionable proposals are Rohin Shah and Anca Dragan’s argument that shrinking reasoning transparency is a design choice—suggesting limits on “opaque serial depth” or equivalent monitorability proof—and Demis Hassabis’s proposed U.S.-led standards body using independent, undisclosed held-out evaluations, initially voluntary up to 30 days before release and potentially mandatory later.
