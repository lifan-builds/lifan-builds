TOP 10 · November 2 technical report; November 3 promotion; weights released October 29

Mistral explains why saving model memory damaged long-running agent performance

Mistral’s initial attention design cut KV memory sixteenfold but hurt agent tasks despite reassuring language-model loss and knowledge scores. The report explains how it removed sliding windows and cross-layer sharing, retained some YOCO sharing, then introduced sparse attention selecting 2,048 keys per query.

Hugging Face shrinks real model architectures to catch silent integration bugs

Model Integration Contracts combine frozen small fixtures, real usage examples and human-reviewed expected outputs, preserving tokenizer files and the relevant attention path. A 66 MB UMT5 fixture detected future-token leakage that ordinary execution missed; the reproduced CI check took 13.4 seconds on CPU, excluding setup.

TOP 10 · November 2 paper, 13:12 UTC; November 3 benchmark announcement

Ai2’s StateBench separates retrieving facts from tracking changing world state

StateBench distinguishes immutable facts, latest-value updates, accumulated changes and assignments that depend on other variables. Tested frontier models handle easier cases but fall to 13% or below on the longest general-finite problems; directly trained recurrent and hybrid variants generalize much farther on several levels.

Local voters back data-center restrictions, adding concrete barriers to AI expansion

Reported results show data-center charter amendments winning in Trenton, Pataskala, Granville, Upper Sandusky and Conneaut, with roughly 65–82% support among yes/no votes. OpenHands brings model post-training into the agent harness builders already use

OpenHands and Snowflake reuse configured prompts, tools, skills and Harbor tasks for RL rollouts, recording exact sampled tokens while excluding prompts and tool responses from the loss.
