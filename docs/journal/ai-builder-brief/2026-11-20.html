TOP 10 · November 19, 2026 preview release

Google adds on-demand Tool Retrieval to the Gemini Interactions API

Google launched Tool Retrieval in the Gemini Interactions API for `Gemini 3.6` and all `Gemini 4` models, letting agents keep libraries of 50+ or hundreds of tools on standby by adding `{"type": "tool_search"}` and marking infrequent functions or remote `mcp_server` tools with `defer_loading: true`. The model sees deferred tool names and descriptions up front without paying prompt tokens for full parameter schemas until it emits a `tool_search_call`, keeping prompt prefixes stable for prefix caching across turns.

TOP 10 · November 19, 2026 API release

OpenAI launches GPT-Live-1.1 API with $0.02/minute WebRTC Standby billing

OpenAI exposed `gpt-live-1.1` on `v1/live/sessions`, bringing the full-duplex multilingual voice model powering ChatGPT Plus and Pro to external developers with improved accent consistency, alphanumeric precision, transcription accuracy, and plain-language backend delegation instructions. Alongside the model update, OpenAI shipped an opt-in `Standby` mode for both `gpt-live-1` and `gpt-live-1.1` WebRTC sessions that pauses model inference after a configurable 5–60 second silence threshold while holding the media connection open for automatic speech resume.

TOP 10 · November 19, 2026 developer API availability (upgraded from November 18 consumer rollout)

Google opens Genie 4 interactive world model in the Gemini API

Moving beyond yesterday's Google AI Ultra subscriber preview, Google made `models/genie-4` callable via the `v1beta` Interactions API and Google AI Studio using `@google/genai` (WebRTC or WebSocket) and `google-genai` (async WebSocket) with ephemeral session tokens. Seeded from text, a 16:9 reference image, or both, `genie-4` streams continuous interactive 720p/24fps video and synchronized 48 kHz stereo audio steered live by `WASD`/arrow inputs and mid-session text events, embedding imperceptible SynthID watermarks on every output.

TOP 10 · November 18, 2026 CISA KEV listing; May 7 advisory

CISA adds actively exploited LiteLLM sandbox-escape RCE (CVE-2026-40217) to KEV

CISA placed `CVE-2026-40217` (`GHSA-wxxx-gvqv-xp7p`, CWE-420) on its Known Exploited Vulnerabilities catalog with a binding federal remediation deadline of December 2, 2026 under BOD 26-04 after observing active in-the-wild exploitation against exposed AI proxy deployments. In BerriAI LiteLLM versions `>= 1.81.8` and `< 1.83.10`, the `POST /guardrails/test_custom_code` endpoint executes user-supplied Python inside a hand-rolled sandbox that attackers can escape via bytecode rewriting to run arbitrary code inside the proxy process—yielding `root` execution in the default Docker image.
