TOP 10 · November 2 original experiments and publication

MIT researchers edit Qwen’s weights to remove loops without gradient training

GPT-6 Astra inspected Qwen3.5-0.8B with a budget of 50 batched forward passes, then altered 131,072 weights in two MLPs; author-reported MATH-500 rose from 7.9% to 48.1%, and a Hugging Face rerun scored 51.0% on the edited checkpoint. The mechanism removes a direction associated with repetitive reasoning, rather than demonstrating general acquisition of mathematical ability: edits to a non-looping Gemma model produced no established gain.

TOP 10 · November 2 engineering retrospective; migration predates publication

OpenAI explains how Pando removes Git bottlenecks under coding-agent load

OpenAI reports Pando now serves all development in its monorepo, cutting median push latency nearly 80% while delivering almost a petabyte daily. The newly explained design coordinates branches independently and reuses immutable packfiles, trading repository-wide snapshots and minimal transfers for parallel writes and cacheable reads; individual branches retain ordered updates.

TOP 10 · November 1 original technical synthesis

Phil Schmid explains how Code Mode replaces repeated tool-call round trips

Schmid shows how an agent can receive typed tool interfaces, write one orchestration script, filter intermediate results in memory and return only useful output, rather than repeatedly putting raw API responses into model context. His example chains project discovery, parallel issue queries and conditional actions; the host bridge can retain credentials and enforce permission checks on each underlying call.

TOP 10 · November 2 research release

Anthropic releases FlashProve to verify inference against committed model weights

FlashProve supplies code, a protocol and Lean proofs for checking that output matches a committed model without exposing its weights. Anthropic reports roughly 110 tokens/second on 4-bit Llama 4 Maverick using one H100, but proving costs about 70–95 times ordinary inference GPU time.

TOP 10 · November 3 models, analysis and v1.2.0 release; repository created October 2025

Hindsight releases small decision models to reduce agent-memory generation costs

A 0.8B decision model returns typed judgments and probabilities for memory relevance, consolidation and refresh decisions, leaving generative models to write changed observations and final answers. Vendor evaluations reduce Gemini-3.8-Flash cost from $147 to $61 per thousand cases, but its reflect score slips from 94.1% to 91.2%; some cheaper backends become more expensive.

TOP 10 · November 3 experiment and explanation; CUGA repository created September 2025

IBM’s CUGA comparison shows harness configuration can dominate multi-app completion

With GLM-5.3-flash held constant, IBM reports 73/90 AppWorld tasks completed by CUGA, 42 by Hermes and 27 by Deep Agents; all three variants passed in 20/30, 8/30 and 2/30 scenarios respectively. CUGA decomposes work by app, narrows tools, executes Python, checks mutations and audits missed pagination.

TOP 10 · November 3, 01:25 UTC v2.1.317 release

Claude Code adds blocking hooks and clearer controls for unattended runs

The release adds an SDK hook option, `onFailure: "block"`, so a failing callback can stop the action, plus warnings about unexpected connectors on scheduled tasks and checks before tools send the account email address to the network. It also corrects headless runs reporting success after losing transcript or configuration writes, although full NFS exports may still escape detection.

Legora explains how privacy constraints reshape agent evaluation and product design

Jacob Lauritzen describes testing legal agents in synthetic worlds containing large document rooms while categorizing production failures into roughly 10–20 types, rather than freely inspecting confidential client traces.
