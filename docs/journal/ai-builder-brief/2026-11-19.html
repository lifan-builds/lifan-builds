TOP 10 · November 18, 2026 changelog

GitHub CLI v2.105.0 adds `gh event listen` to replace agent polling loops

GitHub CLI v2.105.0 integrates GitHub Event Streams so developers and coding agents can block on pull request state transitions, submitted reviews, merge conflicts, and completed check suites via `gh event listen` instead of repeatedly polling APIs. The command streams newline-delimited JSON and exits after the first matching event by default, supporting `--count`, `--follow`, `--timeout`, `--jq`, `--template`, and `gh event subscription {create,list,view,delete}` subcommands.
