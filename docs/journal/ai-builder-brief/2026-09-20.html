TOP 10 · Original disclosure: September 17, 2026

Plugin4Shell exposes a cross-agent zero-click supply-chain RCE

AIR Security disclosed Plugin4Shell, a repository-owner attack that exploits a ref/SHA ambiguity in plugin installation. Four major coding agents—Claude Code, OpenAI Codex, GitHub Copilot and Gemini CLI—could check out a pinned-looking SHA while executing a different resolved revision.

Anthropic proposes public metrics for the pace of frontier-lab development

Anthropic’s Institute proposes three inspectable measurements: how much AI assists AI R&D, whether oversight keeps pace with agent activity, and how compute is allocated between capability and safety work. It publishes an internal snapshot and describes action coverage, review latency, escalation rate, and compute shares rather than only model benchmarks.

Zhipu’s ZCode upload incident turns default telemetry into a live trust failure

A public Z.ai feedback report describes reproducible ZCode 3.12.3 workspace snapshots containing .git data, while independent reverse engineering found a small public repository accepted server-side after failed attempts to upload a much larger private project. Z.ai said repository Wiki/code-indexing could trigger uploads, claimed data was deleted, and said the issue was fixed; ZCode 3.14.0 lists an abnormal-upload fix.
