OpenAI reports Codex removing 800,000 lines while cutting maintenance cost

OpenAI’s Core Experimentation team says five engineers used GPT-6 Astra and GPT-6.1 Sol to merge more than 1,400 maintenance pull requests, delete over 800,000 lines, cut one container image 48% (3.31GB to 1.72GB), and reduce median CI time from roughly 10 minutes to 4.5. StateHarness turns project state into a tested runtime for coding agents

The StateHarness preprint keeps a compact record of the current problem, hypotheses, findings, decisions, repository relationships, and unfinished work; support prompts search affected callers, tests, and documentation, while a separate diagnostic session revisits history when warning signals accumulate. A new synthesis makes agent identity a set of testable preservation claims

Val Alexander’s Hugging Face essay argues that self-improving agents need explicit continuity tests for goals and values, role, memory provenance, and behavioral policy; a stable identifier or unchanged instruction file does not prove the updated model interprets anything the same way. Its proposed LIP-Eval protocol compares frozen, sham-update, and evolving lineages, evaluates rejected candidates, keeps acceptance tests outside the candidate’s mutation scope, and reports properties separately rather than hiding drift in one score.

Interaction-as-a-Judge tests software by using it instead of reading only code

The Interaction-as-a-Judge preprint has computer-use agents interact with generated applications, releasing 6,858 human-preference/trace pairs and 222 human-verified requirement labels. Compared with code-only judging, interactive evaluation improved preference prediction from 65.6% to 69.1% and requirement verification from 77.0% to 81.6%; at inference time it repaired 75.5% of broken requirements within five attempts versus 55.4% for code-only self-feedback.

Chinese research explains how agents escape long-horizon belief traps

A new Chinese technical analysis of the PoS framework explains “Belief Trapping”: an agent can keep acting while its verified belief state stops changing in ways that address unresolved information or achievement gaps. PoS maintains explicit entity/state/relation beliefs, a Belief Sentinel for consistency and evidence checks, and recovery constraints for static, cyclic, or drifting behavior.
