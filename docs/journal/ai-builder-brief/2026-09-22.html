10 source-linked stories · September 22, 2026

Agent capability is advancing, but the sharper near-term shift is architectural: open harnesses, typed decision models, structured memory, and explicit security boundaries are becoming as consequential as another benchmark point.

01

TOP 10 · Original report: September 21, 2026

Meta Muse zero-day exposes the security cost of privileged agents

Patrick Wardle found that any local app or terminal command could change Muse’s undocumented transcription endpoint, exfiltrate the account token, and then use Muse’s privileges to read or write files, take photos, or act through connected services. Ars Technica also reported Amazon blocking Muse shopping access; Meta later hot-fixed the flaw according to The Verge.

AWS open-sources Strands Harness as a portable agent runtime

AWS released Strands Harness as an Apache-2.0 Python/TypeScript agent harness bundling tools, context and memory, designed to run locally or across AWS, Google Cloud, Azure, Modal, Cloudflare and other environments. AWS reports comparable accuracy at 28% lower token cost; The Register and SiliconANGLE describe the multi-cloud deployment model.

Simon Willison’s Jev analysis identifies a cheap “decision model” primitive

Willison read TypeSafe’s Jev as a new model shape: text or semi-structured state in, typed probabilistic decisions out—yes/no, choice distributions, scores and confidence—at $0.042 per million input tokens with parallel questions.
