Jepsen finds 96 ParticleDB failures and challenges AI-era quality claims

Testing versions 1.1.4 through 1.1.18.11.rc-22 uncovered 96 issues, all but three on healthy single nodes, including lost writes and broken constraints; Orkes says 1.1.19-rc.13 fixes everything, but Jepsen has not tested it. The newly published analysis explains how roughly 2,000 lines of generative differential tests exposed failures beneath expansive documentation and repeated LLM claims that bugs were fixed.

DeepSeek opens a proactive-agent prototype that budgets human attention

The MIT-licensed dsh-superagent watches one GitHub repository and optionally Feishu, routes authorized requests into separate worker sessions/directories, and returns results to the originating conversation. Its concrete design separates incoming context from authority, defaults inferred work to observation, and revalidates mandates before resuming; the panel emphasizes work needing people.

Prospero turns blocked commands into resumable work with bounded waits

Chris Wellons explains a native C++ harness built around deadlines: permission requests time out to denial, long shell commands become background jobs, and stopping commands terminates their process trees. Passive rendering avoids continuously redrawing an idle interface, while detachable engines support remote work; the free Community build omits bundled remote engines included in Professional.

Memdoor publishes small-model team traces that expose reviewer-induced regressions

A reproduction of GVS5H’s planner/ideator/solver/manager loop reports 49 successes in 50 runs across ten LiveCodeBench Hard problems repeated five times, with requests, programs and hidden-test verdicts published. Median model time was 40 minutes and median cost $0.39; one failure followed a reviewer inventing a wrong counterexample and replacing correct code, while two other regressions recovered expensively.

SAM traces Gemini-wide prompt failures to one transformed MCP schema

Simple Agent Manager found that OpenCode converted nullable JSON Schema type arrays into `anyOf` while retaining sibling fields, producing a shape Vertex rejected before inference. One invalid tool field rejected the entire declaration list; scanning 149 tools found 42 offending nodes across twelve tools, prompting rewritten nullable branches and tests before and after the adapter transformation.

Talos finds malware using models to prioritize stolen victims’ assets

Cisco Talos’s newly published VOLTA analysis describes an optional post-theft LLM stage that assembles stolen information into an assessment of monetizable assets, with fallback models when responses refuse.
