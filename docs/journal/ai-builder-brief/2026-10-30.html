TOP 10 · October 29 incident; October 30 technical analysis and correction

Cursor confirms malicious Claude Code extension reached up to 5,000 users

Cursor distributed a modified `anthropic.claude-code` 2.1.313 between approximately 09:27 and 20:35 UTC, with code that installs SSH persistence and sends host details before any conversation begins. Cursor removed it, rebuilt its marketplace and disabled the attacker’s server; affected machines still need remediation because uninstalling alone can leave persistence.

TOP 10 · October 28, 2026 technical retrospective

PostHog shows how shared agent state can invalidate model comparisons

Alex Lebedev documents one benchmark run reusing another’s memory 46 seconds later, while another skipped a real issue because an earlier agent had already handled it. The useful mechanism is contamination through writable memory, telemetry, query history and review comments—not simply training-set leakage; PostHog moves toward resettable VMs containing restored real-data slices after recorded MCP responses fail on novel queries.

TOP 10 · October 29 public disclosure; July–September private reports

EMBRACE research exposes broken browser boundaries across five AI assistants

Forever Security documents separate failures in Cursor, Copilot, Codex, VS Code and Claude Desktop: hostile page content reaches agent instructions, a page supplies a false address, or local previews read outside their project. The most concrete design lesson is to enforce boundaries on workers and host bridges as well as top-level pages; the reported Cursor chain also needed a user keystroke and model-dependent compliance.

DiffuSpace releases Clover diffusion weights for faster coding-agent experiments

Clover-35B-A3B-Preview adapts Qwen3.6 into a 35B-total, 3B-active block-diffusion model with Apache-2.0 weights and SGLang/llama.cpp implementations. Its technical explanation separates compressed causal history from bidirectional interaction within each noisy block; the card defaults to 32-token blocks and a 0.95 confidence threshold.

TOP 10 · October 28, 2026 experimental analysis; OpenWiki repository dates to June 22

LangChain connects compiled memory to evidence paths and measures tradeoffs

Eugene Liu tests a compiled wiki on 111 synthetic insurance documents with 972 controlled facts, then adds typed links connecting claims, paragraphs and superseding documents. Cross-document accuracy rises from 0.10 with keyword search to 0.52 with the wiki; adding the graph reportedly improves accuracy another 27% and lowers cost per correct answer 58%.

TOP 10 · October 29 practitioner analysis and Anthropic response; behavior predates this window

Claude Code telemetry reveals costly background summaries beyond visible conversations

Flamerix’s one-week OpenTelemetry breakdown attributes 16.4% of estimated spend to status summaries that repeatedly send active background agents’ transcripts to their model. Anthropic confirms the mechanism but reports a different population: about 2% of list-price cost across telemetry users and about 6% in the terminal; idle agents do not incur these calls.
