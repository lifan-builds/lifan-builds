TOP 10 · November 11, 2026

AWS makes real service behavior the test oracle for agents

AWS's new emulator and Swami Sivasubramanian's engineering account describe a powerful sequence: generate scenarios from API models, make the tests pass against real AWS, then implement the emulator against those tests. The CC0 release covers more than 400 API models across 200 services, with deterministic merge checks and adversarial agent reviews; internal use is vendor-reported.

TOP 10 · November 10, 2026

AlphaProof Code verifies Signal properties while protecting the specification

DeepMind published approximately 6.5 million lines of Lean proofs for specified properties of libsignal 0.105.4 compiled to AArch64 in a command-line harness. Human-approved specifications, a protected baseline and deterministic comparison constrain prover agents, while Lean checks their proofs: the transferable lesson is to protect what counts as success independently from whoever generates the solution.

Google pairs Hydrogen with Carbon to reduce agent execution costs

Gemini 4 Hydrogen is rolling out through AI Studio and the Gemini API at $1.50 input/$7.50 output per million tokens, flat through its 1M-token context. Antigravity's new Orchestrator hands routine execution from Carbon to Hydrogen and can return to Carbon when the trajectory needs deeper reasoning; Orchestrator is rolling out to Ultra subscribers, while Hydrogen also reaches Pro.

Shopify rebuilds its mobile app around executable feedback for agents

Shopify's new retrospective explains how 30 engineers rebuilt a 300-plus-screen app in Swift and Kotlin over twelve weeks, with agents writing most implementation. Headless ViewModels and terminal tooling shortened feedback from simulator navigation to milliseconds; executable architecture, small checkpoints and human approval constrained parallel work.

Gemini Decisions replaces repeated generation with fast multimodal choice scoring

Google's available Decision 1 endpoint scores bounded choices in one forward pass, supporting 256K multimodal input and up to 1,000 questions at $0.10 per million input tokens, with no output-token bill. Its reported 150–250ms end-to-end latency concerns contexts through 16K and roughly 1–100 questions, not the maximum limits.

Microsoft shows tiny checkpoint edits can hijack tool-using agents

Lazarus modifies fewer than ten dormant neurons to recognize a trigger and force payload tokens, making model provenance an execution-security concern. The attacker must already be able to alter weights; a trigger string cannot compromise a clean checkpoint, and the paper's strongest results use additional fitting rather than purely analytic edits.

Anthropic's amended S-1 now says it has determined that its Responsible Scaling Policy's AI research-and-development threshold is met, materially changing the November 2 filing's warning that this might happen imminently. Chrome ships tested web guidance and a trace-driven repair workflow

Modern Web Guidance 1.0 combines reviewed skills, browser-compatibility data and a limited static modernization scanner; Chrome reports guide-defined check pass rates rising from 52% to 91%. TOP 10 · November 11, 2026 disclosure

AWS discloses MCP registry flaws that survive incomplete upgrade cleanup

AWS describes administrator escalation in customer-run mcp-gateway-registry 1.0.9–1.24.7, fixed in June's 1.25.0, and a separate SSRF flaw affecting 1.0.3–1.34.0, fixed in 1.35.0. The consequential new public guidance is that upgrading preserves previously written privileged group mappings and upstream addresses, so it cannot undo earlier unauthorized configuration changes.
