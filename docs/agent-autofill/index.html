How it works

  1. Install Agent Autofill on your Mac and connect the sources you choose.
  2. Pair an agent and approve the data it can read. Remote clients use scoped, expiring grants.
  3. The broker returns selected information. Your agent handles the task in its own tools.

Gmail access

Connect Gmail to find a message, read information for an email task, or retrieve a recent sign-in code for a specified recipient. The updated Gmail API connector in the local development build requests read-only access; this change has not yet been released publicly. Agent Autofill does not send, edit, or delete email.

OAuth setup uses a Google Cloud Desktop client supplied by you. Google verification belongs to that client's project; installing this open-source app does not verify a different project. Older IMAP connections may retain broader Google permissions until you revoke and reconnect them.

Know where your data goes

Saved records are encrypted locally, and connector credentials live in the operating-system credential store. When you authorize an agent to read information, returned content becomes available to that agent and may be sent to its model provider. Choose the agent and its data settings accordingly.

The broker does not submit forms or make purchases. Its local storage does not make a separate cloud AI service local.
