Every time an AI agent hits a form, you end up retyping your address, pasting a password into chat, or hunting down a verification code. Agent Autofill is a local-first personal vault for AI agents on your Mac.

Start from Chrome. It organizes your saved addresses, confirms what is Home versus Work, and remembers those meanings across future tasks. When a site needs a login or a two-factor code, it hands off a one-time, origin-bound token and pulls the code from your connected email or Messages—so your raw password never enters model context. And before anything is submitted, you stay in control. Agent Autofill. Autofill, for agents.

1. Import locally

Connect the sources you choose or import saved addresses and logins directly from Chrome on your Mac—no plaintext CSV exports.

2. Approve exact scope

Pair an MCP client (agent-autofill mcp-install) and approve specific fields or expiring grants. Website logins use a one-time origin-bound Chrome handoff (credential.use).

3. Stop before submit

The broker returns only approved fields or verification codes. Your agent prepares the form in its own tools and pauses for your confirmation before submission.

Gmail access

Connect Gmail to find a message, read information for an email task, or retrieve a recent sign-in code or verification link for a specified recipient. Version 0.1.2 uses the read-only Gmail API connector (gmail.readonly scope) by default and never sends, edits, or deletes email.

OAuth setup uses a Google Cloud Desktop client supplied by you. Google verification belongs to that client's project; installing this open-source app does not verify a different project. Older IMAP connections may retain broader Google permissions until you revoke and reconnect them.

Know where your data goes

Saved records are encrypted locally in SQLite with AES-GCM, and vault keys plus connector credentials live in the macOS Keychain. Authorized fields returned to an agent may be sent to its model provider, while the Chrome extension handoff (credential.use) keeps website passwords out of model context.

The broker is strictly information-only: it does not navigate, submit forms, or make purchases. Its local storage does not make a separate cloud AI service local.
