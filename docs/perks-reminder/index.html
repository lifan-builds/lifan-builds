Physical-card isolation

Tracks each physical card separately—even when a household holds multiple copies of the same card—using nickname and ending-digit labels.

Catalog + usage guides

Pairs monthly, quarterly, semiannual, and anniversary reset logic with practical Benefit Usage Guides covering qualification rules and caveats.

No bank login required

Never asks for bank passwords or third-party aggregators. Export or restore your entire card and benefit history as clean JSON at any time.
