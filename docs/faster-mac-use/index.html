macOS 14+ & Accessibility

            
The compiled Swift fmu-ax daemon and Apple Silicon Vision OCR require macOS with Accessibility permission granted to your terminal or IDE.

          

          

            
MV3 Extension vs. Headless

            
Driving visible Chrome "🤖 Agent" tab groups uses the included MV3 extension (ws://127.0.0.1:19222/ext); without it, fmu runs in a background Chromium worker.

          

          

            
Unminimized Window OCR

            
AXUIElement actions work on any background or minimized window, while app.ocr() requires the target window to be unminimized (it may stay occluded).
